LA PUERTA DE LA INTELIGENCIA
----------------------------
Al abrir la app por primera vez pide configurar la IA antes de entrar. Es a
propósito: sin un proveedor validado el Guardián no puede preguntar ni evaluar.

1. Elige un proveedor: 22 en la nube (OpenAI, Claude, Gemini, OpenRouter,
   Groq, Mistral, DeepSeek, xAI, Together, Fireworks, Perplexity, Cerebras,
   DeepInfra, Hyperbolic, Nebius, SambaNova, Novita, GitHub Models, Moonshot,
   Z.ai, Qwen, SiliconFlow) u 8 locales (Ollama, LM Studio, llama.cpp, vLLM,
   Jan, GPT4All, KoboldCpp, text-generation-webui), o "Otro" con tu URL.
2. Escribe URL, modelo y clave (los locales no llevan clave).
3. Pulsa "Probar conexión": la app hace una llamada REAL.
4. Sólo si responde, "Continuar" se enciende. Guardar una clave no basta.

Puedes guardar varios perfiles: basta con que uno funcione.

IA LOCAL (GRATIS, SIN INTERNET)
-------------------------------
1. Instala Ollama (ollama.com).
2. En una terminal:  ollama pull llama3.1:8b
3. Comprueba que http://localhost:11434 responde.
4. En la puerta elige Ollama, URL http://localhost:11434/v1, modelo
   llama3.1:8b y pulsa "Probar conexión".

Si dejas el modelo vacío, la app pregunta al servidor qué modelos tiene.

PRIVACIDAD
----------
La clave se guarda SÓLO en este equipo y viaja únicamente al proveedor que
elijas. Ningún servidor de la app la recibe: no hay servidor.
El progreso vive en el navegador (localStorage) o en el perfil de la app de
escritorio. Desde Ajustes > Descargar copia guardas todo en un JSON; hazlo cada
semana, es lo único que lo devuelve si el navegador borra sus datos.

Opcional: en Ajustes > Cuenta y base de datos puedes conectar un proyecto
Postgres (Supabase) para que el mismo progreso siga en el movil, el PC y la web.
Cada cuenta solo puede leer su propia fila. Sin conectar nada, no se envia nada.

COMPILAR
--------
node build.mjs                    regenera el HTML único
bash tests/run-all.sh             todas las pruebas

cd desktop
npm install
npm run dist:win                  .exe portable
bash pack-platforms.sh            Linux x64 + macOS arm64 + macOS Intel
                                  (descarga reanudable en desktop/vendor/)

Detalles, firma de código y errores frecuentes en docs/MANUAL-DE-DESPLIEGUE.md.

AVISOS AL ABRIR LOS BINARIOS
----------------------------

"Ejecutar de todas formas". macOS: clic derecho sobre la app > Abrir > Abrir.
